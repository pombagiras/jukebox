# 🍸 NEON BRUTALIST BAR // AUTOMATIC JUKEBOX 🍸

> **AUTO-STOP ACTIVATED // ONE DRINK AT A TIME // 38 SHOTS OF POST-PUNK // SYSTEM OVERRIDE**

Uma jukebox visceral e brutal que transforma cada bebida clássica em uma experiência sonora pós-punk. 38 drinks. 38 músicas de IA. Um bar automático onde a música flui como álcool néon.

---

## 🥃 O QUE É ISSO?

Um **bar digital neon-brutalist** onde cada bebida icônica do mundo dos coquetéis é sincronizada com uma composição musical gerada por IA. Da tequila shot à death in the afternoon, cada drink tem sua própria trilha sonora sombria.

**ENTRE NO BAR. ESCOLHA SEU VENENO. DEIXE A MÚSICA QUEIMAR.**

### 🎯 Conceito
- **38 Bebidas Clássicas** = 38 Faixas Musicais
- **Sistema Auto-Stop**: Só toca um drink por vez (como no bar de verdade)
- **Modo Sequencial**: Sirva todos os 38 drinks em ordem automática
- **Estética Cyberpunk**: Néon + Brutalismo + Post-punk vibes

## ⚡ CARACTERÍSTICAS

### 🎨 Design Neon-Brutalist
- **Cores Néon Vibrantes**: Pink, Blue, Green, Yellow
- **Bordas Brutais**: Linhas grossas e geometria dura
- **Botões Giratórios**: Animação hipnótica contínua
- **Cursor Crosshair**: Como mira de sniper no bar

### 🎵 Sistema Inteligente de Playback
- ✅ **Auto-Stop**: Para automaticamente outras músicas quando você clica
- ✅ **Destaque Visual**: Drink tocando fica com outline néon verde
- ✅ **Navegação Sequencial**: Next/Prev pelos 38 drinks
- ✅ **Modo ALL 38**: Toca TODOS os drinks em sequência automática
- ✅ **Scroll Suave**: Foca automaticamente no drink tocando

### 📱 Mobile-First & Responsivo
- Interface otimizada para smartphones
- Botões com área de toque adequada
- Grid adaptativo (1 coluna em mobile, múltiplas em desktop)
- Performance otimizada (lazy loading, animações reduzidas)
- Suporte completo a gestos touch

## 🚀 COMO USAR

### Instalação
```bash
# Clone este bar do submundo digital
git clone [seu-repo-aqui]
cd neon-bar-jukebox

# Simplesmente abra o arquivo
open index.html

# Ou sirva localmente:
python -m http.server 8000
# Acesse: http://localhost:8000
```

### Modo de Uso

1. **Escolha seu Drink**: Clique em qualquer bebida do grid
2. **Use os Controles**: Botões giratórios para navegação
3. **Modo Automático**: Pressione "ALL 38" para sequência completa
4. **Auto-Stop**: Sistema inteligente para todos os outros drinks quando você escolhe um novo

**⚠️ AVISO DO BARMAN**: Consuma com moderação. Uma música por vez.

## 🔧 FEATURES TÉCNICAS

### Animações CSS
```css
@keyframes rotateBtn {
  from { transform: rotate(0deg); }
  to { transform: rotate(360deg); }
}
```
- Botões giram continuamente (2s a 5s por ciclo)
- Texto interno permanece legível (contra-rotação mental)
- Performance otimizada com `prefers-reduced-motion`

### Sistema Auto-Stop
```javascript
function stopAllOthers(exceptionIndex) {
  // Para TODOS os players menos o escolhido
  // Implementado via YouTube IFrame API postMessage
}
```

### Responsividade Avançada
- Breakpoints: 768px, 480px, 360px
- Grid: `repeat(auto-fit, minmax(280px, 1fr))`
- Fontes fluidas: `clamp(2rem, 8vw, 4rem)`
- Touch events otimizados
